# Packer Image for Ubuntu

This Packer configuration creates a reproducible Ubuntu 24.04 image for testing purposes.

## Setup

1. Ensure that both `packer` and VMware Workstation are installed.
2. Run `packer init .` to download the `vmware-iso` plugin.
3. Build the image with `packer build packer/ubuntu.pkr.hcl`.

This will create the Ubuntu VM. To avoid potential VNC issues, it's recommended to open the VMware window before running Packer.

If you need to customize the VM, you can edit `packer/scripts/setup.sh` to handle post-installation tasks.

For any issues with packer, consult the [docs on debugging](https://developer.hashicorp.com/packer/docs/debugging).
## Running Signal Builds

The `./execute_on_clone.py` script wraps around `vmrun` to:

- Create a shallow (linked) clone of the `.vmx` file generated by Packer
- Run the `scripts/signal.sh` script to build the Android app
- Copy results via SSH to the local machine
- Perform teardown operations to remove the created clone

> [!IMPORTANT]
> **Note:** The script is a bit of a hack. To modify the number of runs, tags, or arguments passed to `build_signal.py`, check the main function in `./execute_on_clone.py` and line 36 of `scripts/signal.sh`.
